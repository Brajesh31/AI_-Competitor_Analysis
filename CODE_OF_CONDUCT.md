# Code of Conduct

## Our commitment
The project welcomes constructive participation from people with different backgrounds and levels of experience. Communication should remain respectful, practical, and focused on improving the software.

## Expected behavior
- Be respectful and considerate.
- Critique code, implementation, evidence, and assumptions rather than people.
- Explain disagreements with technical reasoning.
- Accept good-faith corrections.
- Respect privacy, security, and third-party data rights.
- Keep issues, reviews, and discussions relevant and actionable.

## Unacceptable behavior
Harassment, discrimination, threats, personal attacks, doxxing, intimidation, deliberate disruption, and publishing private information or credentials are not acceptable. Do not publish confidential company research or personal data obtained through scraping.

## Reporting
Report conduct concerns privately to the project maintainer, Brajesh Kumar, through the private contact route available from the maintainer's GitHub profile. Avoid posting sensitive details publicly.

Reports will be reviewed as fairly and confidentially as possible. Maintainers may edit or remove contributions and restrict participation when needed to protect the project community.

## Scope
This code applies to project issues, pull requests, reviews, repository discussions, and spaces where a person represents this project.
