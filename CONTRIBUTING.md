# Contributing

1. Read the README and understand the Next.js app-router structure.
2. Create a focused branch and avoid unrelated generated or local files.
3. Run `npm ci`, then use `npm run lint` and `npm run build` where applicable.
4. Never commit Gemini, SerpAPI, or other credentials.
5. Add or update tests and documentation when changing API routes, scraping, AI prompts, or exported CSV shape.

Pull requests should describe the user-visible change, data sources affected, validation performed, and any privacy or rate-limit implications.
