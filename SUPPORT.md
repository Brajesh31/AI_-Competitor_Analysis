# Support

## Read the guides
Start with the [README](README.md), [installation guide](docs/installation.md), [configuration guide](docs/configuration.md), [API reference](docs/api.md), [FAQ](docs/faq.md), and [troubleshooting guide](docs/troubleshooting.md).

## Include useful diagnostic details
For a reproducible issue, provide:
- Browser and operating system, where relevant.
- Node.js and npm versions.
- Command used and exact route/feature.
- Expected and actual behavior.
- Sanitized error message or stack trace.
- Whether Gemini or SerpAPI is involved.
- Whether the issue is reproducible without provider credentials.

Do not include API keys, customer data, confidential company research, or raw restricted content.

## Where to ask
Use GitHub Issues with the matching bug, feature, or documentation template. For suspected security vulnerabilities, use the private reporting route described in [SECURITY.md](SECURITY.md).

## Support boundaries
Search output can be stale, incomplete, or wrong. AI confidence is not proof of a business relationship. The project is not a legal, investment, or procurement decision system.
